# Источники одежды и движений

`office-outfit-office_v4.blend` — редактируемый источник деловой одежды для текущего MetaHuman. Модель создана генератором `tools/author_avatar_outfit.py` в Blender 4.5.15 LTS. Основа рубашки/брюк и эталонные веса происходят из Epic MetaHuman Creator Core Data Default Garment UE 5.6.1; новые геометрия и детали описаны в генераторе. Условия Epic для исходных материалов сохраняют значение; собственная обработка не превращает их в независимо лицензированный сторонний ассет.

Движения создаются `tools/author_avatar_motion.py` по экспортированному реальному reference skeleton. Сторонние клипы не используются. Настройки и численные результаты генерации записаны в `motion-recipe.json`; в Unreal отдельно проверяются все кадры и настоящий игровой контроллер.

Полная процедура и границы фактических проверок: `docs/avatar-authoring.md`. Хеши источников и runtime-ассетов: `assets/manifest/office-avatar.json`.
