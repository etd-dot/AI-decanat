# Целевая среда и недостающие компоненты

Это подготовка стенда, не измеренные минимальные требования готового продукта. Покупка техники и платных сервисов не выполнялась.

Обновление 2026-11-06: доступен локальный Windows-ПК с Ryzen 5 3600, 16 GiB RAM и RTX 3080 10 GiB. Установлены VS 2022 Build Tools, MSVC 14.38, Windows SDK 22621, UE 5.6.1/MetaHuman Core Data и ACE/Mark. Реальный packaged runtime и голосовой диалог уже проверены. Фактические характеристики, ограничение RAM и команды — [windows-environment.md](windows-environment.md), самостоятельная поставка — [windows-distribution.md](windows-distribution.md).

## Выбранное направление

Windows 11 x64, NVIDIA GPU; проверены UE 5.6.1 и официальный `nv_ace_reference-ue5.6-v2.5.0rc3.zip` с установленной версией 2.5.0-20250614-2282. Локальный Mark 3.0 работает на этом стенде, editor/game targets и Development packaging проходят. Точные SHA и границы проверок — `assets/manifest/desktop-stack.json` и `ace-runtime.json`. Production-релиз этим не утверждён.

Основание: [инструкция ACE 2.5](https://archive.docs.nvidia.com/ace/ace-unreal-plugin/2.5/ace-unreal-plugin-install.html) указывает UE 5.5/5.6. [Матрица функций](https://archive.docs.nvidia.com/ace/ace-unreal-plugin/2.5/ace-unreal-plugin-support-matrix.html) поддерживает локальные лицевые модели на Windows/NVIDIA и отмечает Linux как Unsupported. Поддержка Linux у базового удалённого клиента не означает поддержку нужной нам локальной ветки.

Первый кандидат мимики — `LocalA2F-Mark` / `NvAudio2FaceMark`, diffusion 3.0, выбранный для качественного режима. Это направление ассистента, не утверждённый образец. Оставить в поставке одну локальную модель после визуального сравнения на русской речи. Случайный provider, `Default`, `RemoteA2F` и `LegacyA2F` не разрешаются.

## Ресурсный бюджет для первого стенда

Для исследования полного приложения ориентироваться на 32 GB RAM, SSD и NVIDIA Ampere/Ada/Blackwell с 16 GB VRAM. Это инженерный запас под одновременные сцену/персонаж/мимику, не опубликованный minimum и не рекомендация покупать определённую карту. Точный GPU/CPU/драйвер занести в протокол испытаний; достаточность подтвердить FPS, памятью и задержкой под нагрузкой.

Официальные [требования локального Audio2Face](https://archive.docs.nvidia.com/ace/ace-unreal-plugin/2.5/ace-unreal-plugin-audio2face.html) относятся только к мимике: примерно 4.4+ GiB для diffusion, 2.9–3.0+ GiB для regressive, драйвер 551.78 или новее; рекомендации конкретного GPU могут требовать более нового драйвера. Это не общий бюджет MetaHuman-приложения. Параметры создания персонажа в редакторе также отличаются от runtime.

## Открытые зависимости

- Окончательные права на бесплатную production-поставку конкретных моделей; старый Mark-пакет содержит Community License, а не Open Model License.
- Полная акустическая приёмка AEC/перебивания и длительный прогон. Пользователь подтвердил отдельный живой голосовой вопрос и озвученный ответ; это не проверка всех акустических сценариев.
- Чистая Windows и аппаратная матрица за пределами данного ПК. Изолированный локальный runtime уже испытан без сети и путей разработки.
- Реальная подготовленная база вуза. Для текущей демонстрации используется вымышленный набор.
- Отдельная реальная проверка API-ветки при её выборе; подписочная Codex-ветка уже работает, API-fallback выключен.

Первоначально обсуждался ноутбук с RTX 2050; теперь работа идёт на проверенном ПК с RTX 3080. Прежнее короткое ТЗ удалённого подключения — [windows-testhost-checklist.md](windows-testhost-checklist.md). Для RTX 2050 стандартные 4 GB VRAM не покрывают заявленные 4.4+ GiB выбранной diffusion-модели даже без сцены; это исторически предложенный стенд, а не принятая минимальная конфигурация продукта. Аккаунты и пакеты Epic/NVIDIA по-прежнему требуют самостоятельного входа владельца.

## Порядок проверки на целевой машине

1. Получить совместимый engine/plugin/model-комплект по официальным ссылкам, сохранить его SHA-256 и фактические условия распространения.
2. Собрать desktop без ACE, затем с ACE. Подключить настоящие ассеты по `docs/unreal-setup.md`. Исправить несовместимости C++ API по реальным заголовкам, не считать текущие исходники скомпилированными.
3. Проверить единственное слышимое воспроизведение, реальную синхронизацию мимики и очистку её буферов при перебивании. Вызов StopCharacter подготовлен по API ACE 2.5, но runtime-результат ещё не испытан.
4. Выбрать реальные устройства, проверить 48 kHz duplex, AEC и сохранение первых слов реплики. На Mac текущие ASR/TTS/retrieval испытаны синтетическими клипами; этого недостаточно для акустической приёмки.
5. Выполнить матрицу из development-plan.md: packaged build, чистая установка, нагрузка, киоск, 8 часов, факты на вузовской базе, обе реальные ветки ответа.

Без этих результатов нельзя объявить полный продукт рабочим или назвать измеренную минимальную конфигурацию.
